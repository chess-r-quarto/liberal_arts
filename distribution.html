Architecture

すべては「標準正規分布」から派生する

3つの分布はバラバラではなく、標準正規変数 $Z \sim N(0, 1)$ の二乗や比率によって美しく繋がっています。

二乗の和 $\chi^2$

カイ二乗分布

Karl Pearson (1900)

$X = \sum_{i=1}^k Z_i^2$

正規分布に従う変数の二乗を $k$ 個足したもの。理論値と観測値の「ズレの総量」を評価する。

比（正規 / カイ二乗根） $t$

$t$ 分布

Student / Gosset (1908)

$t = \frac{Z}{\sqrt{\chi^2 / k}}$

母分散が未知のとき、標本分散で標準化した平均値が従う分布。サンプル数が少なくても正確に判定可能。

カイ二乗の比 $F$

$F$ 分布

Fisher (1924) & Snedecor (1934)

$F = \frac{\chi_1^2 / k_1}{\chi_2^2 / k_2}$

2つの独立したばらつき（分散）の比率。要因による差が、偶然の誤差より何倍大きいかを判定する。

重要な数理関係： 自由度 $k$ の $t$分布の変数を2乗すると、分子自由度 $1$、分母自由度 $k$ の $F$分布に一致します（$t^2 = F(1, k)$）。
※等分散を仮定したStudentの2標本t検定 ＝ 2群の一元配置分散分析
$\chi^2$

1. カイ二乗分布（Chi-Square Distribution）

ピアソンが考案した「ズレの総量」を測る分布

背景と誕生のストーリー

1900年、カール・ピアソン（Karl Pearson）は「サイコロを振った結果が、理論通りの等確率（1/6ずつ）に従っているか」を客観的に判定したいと考えました。 観測度数 $O$ と期待度数 $E$ のズレは正負両方に出るため、そのまま足すと相殺されます。そこで「標準化したズレの2乗和」 $\sum \frac{(O-E)^2}{E}$ を考案しました。

本質的な定義は「独立な標準正規変数の二乗和」ですが、多項分布に従う度数データのズレも、サンプルサイズが大きいとき中心極限定理によって正規近似され、漸近的にカイ二乗分布に従うことが数学的に証明されています。

主な性質
  • 二乗の和なので、必ず0以上の値をとる（非負・右裾野）。
  • 平均（期待値）は $k$、最頻値（山の頂点）は $k - 2$（$k \ge 2$ のとき。$k=1$ では $0$ で発散、$k=2$ では $0$ が有限の最大値で単調減少）。
  • 歪度は $\sqrt{8/k}$ であり、$k$ が大きくなるにつれて緩やかに正規分布へと漸近する。
実例で理解する

新フレーバー紅茶の「人気の偏り」検定（適合度検定）

60人に3つの新フレーバー（レモン、アップル、ピーチ）を試飲してもらい、1番好きなものを1つ選んでもらった。
【帰無仮説 $H_0$】：フレーバー間の好みに差はなく、母比率は均等（各 $1/3$、期待値各20人）である。

レモン
30人
期待値 20人
アップル
18人
期待値 20人
ピーチ
12人
期待値 20人
// ピアソンのカイ二乗統計量の計算
$\chi^2 = \frac{(30-20)^2}{20} + \frac{(18-20)^2}{20} + \frac{(12-20)^2}{20} = 5.0 + 0.2 + 3.2 = \mathbf{8.40}$
自由度 $3 - 1 = 2$ の有意水準5%臨界値は 5.99。
検定統計量 $8.40 > 5.99$ となり棄却域に入るため、有意水準5%で帰無仮説は棄却される。「味による人気の偏りがない（均等である）」とは言えず、好みに統計的に有意な差があると判断できる。

どんな時に使う？

  • 適合度検定： サイコロの出目や遺伝の法則など、理論通りの比率で生起しているかを大標本で検定する時。
  • 独立性の検定： アンケートのクロス集計表で、「性別」と「支持政党」など2つの質的属性に関連性があるか調べたい時。
  • 母分散の検定： 正規母集団を前提として、標本不偏分散から $\chi^2 = \frac{(n-1)s^2}{\sigma_0^2}$ を用いて検定する時（正規性の仮定に非常に敏感なため注意が必要）。
💡 実務のワンポイントアドバイス

カイ二乗検定は正規近似に基づくため、期待度数が5未満のセルが多いと精度が低下します。$2 \times 2$ 表ではフィッシャーの正確確率検定、一般の分割表ではカテゴリの統合や正確検定（Freeman-Halton検定）を検討します（※イェーツの連続補正は過度に保守的になりやすいため近年は慎重に扱われます）。

$t$

2. $t$ 分布（Student's t-Distribution）

ギネスビールの醸造現場から生まれた「少標本」の救世主

背景と誕生のストーリー

1908年、アイルランドのギネス醸造所で化学者・統計技師をしていたウィリアム・ゴセット（W. S. Gosset）が考案しました。 大麦の品種改良実験などはコストや時間の制約で数個〜十数個程度の極めて小さな標本しか得られませんでした。

従来のZ検定では母分散が既知である必要がありましたが、未知の母分散を標本分散で代用すると、少標本では推定誤差によって誤判定（第一種の過誤）が多発します。ゴセットはこの不確実性を組み込んだ分布を導き、ペンネーム「Student」で発表しました（後にロナルド・フィッシャーが自由度に基づく厳密な数学的定式化を与えました）。

主な性質
  • 正規分布と同様に平均0で左右対称の釣鐘型。
  • 分散は $df > 2$ のとき $\frac{df}{df-2}$（$df \le 2$ では分散は無限大、$df=1$ はコーシー分布となり期待値すら未定義）。
  • 標本分散の不確実性を織り込んでいるため、正規分布よりも頂点が低く、両裾（Fat tail）が厚い。自由度が増大するにつれて標準正規分布 $N(0, 1)$ に漸近する。
実例で理解する

新レシピA vs 定番レシピBの味評価（2標本t検定）

各グループ独立な評価者5人ずつ（計10人、正規母集団・等分散を仮定）に10点満点で味を採点してもらった。
【帰無仮説 $H_0$】：両レシピの母平均に差はない（$\mu_A = \mu_B$）。

新レシピ A（$n_A=5$）
平均 $\bar{X}_A = 8.0$ 点
不偏分散 $s_A^2 = 0.50$
定番レシピ B（$n_B=5$）
平均 $\bar{X}_B = 6.0$ 点
不偏分散 $s_B^2 = 1.00$
// 等分散を仮定したプールした分散（pooled variance）の算出
$s_p^2 = \frac{(n_A-1)s_A^2 + (n_B-1)s_B^2}{n_A + n_B - 2} = \frac{4(0.50) + 4(1.00)}{8} = \mathbf{0.75}$
// t統計量（平均差 / 推定標準誤差 SE）
$t = \frac{\bar{X}_A - \bar{X}_B}{\sqrt{s_p^2(1/n_A + 1/n_B)}} = \frac{8.0 - 6.0}{\sqrt{0.75/5 + 0.75/5}} = \frac{2.0}{\sqrt{0.30}} \approx \mathbf{3.65}$
自由度 $5+5-2 = 8$ の有意水準5%両側臨界値は $\pm 2.306$。
計算値 $t = 3.65 > 2.306$ となり棄却域に入るため、帰無仮説は棄却される。正規性・等分散性の前提のもと、新レシピの平均評価が有意に高いと結論付けられる。

どんな時に使う？

  • 1標本t検定： ある製品の平均重量が規定値 $\mu_0$ と等しいか検定したい時。
  • 2標本t検定（独立）： 2群の母平均を比較する時。※現代の実務では等分散性を仮定しないWelchのt検定が標準的に推奨されます。
  • 対応のあるt検定： 同一被験者に対する投薬前後の血圧変化など、差の平均を評価する時。
  • 回帰係数の検定： 回帰分析において各変数の傾き $\beta$ が統計的に有意か調べる時。
💡 「サンプルサイズ30の目安」の真実

「$n \ge 30$ で正規分布と見なせる」という俗説は、自由度30前後の両側5%点（$t_{0.025}(30) \approx 2.042$）が正規分布の $1.96$ と約4%しか離れなくなる実務上の経験則・便宜的な慣習に過ぎません。数学的には自由度の上昇に伴って連続的に正規分布へ漸近します。

$F$

3. $F$ 分布（Fisher-Snedecor Distribution）

近代統計学の父フィッシャーが拓いた「分散の比較」

背景と誕生のストーリー

1920年代、ロナルド・フィッシャー（Ronald A. Fisher）がロザムステッド農業試験場で、複数の異なる肥料や土壌による収穫量の差を評価するために創案しました（1924年に分散比の対数変換である $z$ 分布として提示され、1934年にジョージ・スネデカーが扱いやすい分散比 $F$ として定式化・命名）。

3つ以上のグループを比較する際、ペアごとに $t$検定を繰り返すと「偶然どれかが有意になってしまう確率（多重性の問題）」が跳ね上がります。そこでフィッシャーは全体のばらつきを「群間のばらつき」と「偶然の誤差ばらつき」に分解し、その比率（分散比）を一括評価する分散分析（ANOVA）を確立しました。

主な性質
  • 正の値同士の比率であるため、必ず0以上の値をとる。
  • 分母自由度 $d_2 > 2$ のとき期待値は $\frac{d_2}{d_2 - 2}$（帰無仮説が真のとき、分母自由度が大きければほぼ $1$ になる）。
  • 分子自由度 $d_1 > 2$ のとき最頻値は $\frac{d_2(d_1 - 2)}{d_1(d_2 + 2)} < 1$ であり、山は1の左側に位置する。
実例で理解する

3台のコーヒー抽出機による濃度差（一元配置分散分析）

マシン1、マシン2、マシン3でそれぞれ4杯（$n=4$、計12杯）抽出し、抽出濃度の平均に差があるかを一括検定する。
【帰無仮説 $H_0$】：3台のマシンの母平均濃度はすべて等しい（$\mu_1 = \mu_2 = \mu_3$）。

マシン 1（4杯）
平均 $\bar{X}_1 = 1.30\%$
群内不偏分散 0.020
マシン 2（4杯）
平均 $\bar{X}_2 = 1.50\%$
群内不偏分散 0.030
マシン 3（4杯）
平均 $\bar{X}_3 = 1.10\%$
群内不偏分散 0.025
// 分散分析表に基づくF値の導出（全体平均 $\bar{X}_{\cdot\cdot} = 1.30\%$）
群間平方和 $SS_B = 4 \times [(1.30-1.30)^2 + (1.50-1.30)^2 + (1.10-1.30)^2] = 0.320$
群間平均平方 $MS_B = SS_B / (3 - 1) = 0.320 / 2 = \mathbf{0.160}$
群内平均平方（プール誤差分散） $MS_W = \frac{0.020 + 0.030 + 0.025}{3} = \mathbf{0.025}$（$df_W = 12-3 = 9$）
$F = \frac{MS_B}{MS_W} = \frac{0.160}{0.025} = \mathbf{6.40}$
分子自由度 $2$、分母自由度 $9$ の有意水準5%限界値は 4.26。
$F = 6.40 > 4.26$ となり棄却域に入るため、帰無仮説は棄却される。単なる抽出ブレ（誤差）を超えて、マシン間で有意な濃度差が存在すると判断できる。

どんな時に使う？

  • 一元・二元配置分散分析（ANOVA）： 3群以上の要因効果を一括検定する時（全体有意となった後は、Tukey-Kramer法などの多重比較で具体的にどのペアに差があるかを特定します）。
  • 重回帰分析のモデル適合度検定： 説明変数の組み合わせ全体が目的変数を有意に説明しているかを検定する時。
  • 等分散性の検定（F検定）： 2群の分散比を検定する手法。※ただし正規性の仮定からの逸脱に極端に弱いため、実務ではルビーン（Levene）検定などが推奨されます。
💡 実務の注意：2段階検定の回避

かつては「F検定で等分散を確認してからStudentかWelchかを決める」という手順が教えられていましたが、この2段階検定は全体の有意水準を歪める問題があるため、現代の統計学実務では最初からWelchのt検定を採用することが強く推奨されています。

$t$

2. $t$ 分布（Student's t-Distribution）

ギネスビールの醸造現場から生まれた「少標本」の救世主

背景と誕生のストーリー

1908年、アイルランドのギネス醸造所で化学者・統計技師をしていたウィリアム・ゴセット（W. S. Gosset）が考案しました。 大麦の品種改良実験などはコストや時間の制約で数個〜十数個程度の極めて小さな標本しか得られませんでした。

従来の正規分布（Z検定）では「母分散が既知」である必要がありましたが、未知の母分散を標本分散で代用すると、少標本では推定の誤差が大きすぎて誤判定を起こします。ゴセットは「標本分散の不確実性」そのものを数式に組み込み、ペンネーム「Student」で論文を発表しました。

主な性質
  • 正規分布と同様に平均0で左右対称の釣鐘型。
  • 標本分散のブレを織り込んでいるため、正規分布よりも山が低く、両裾野（Fat tail）が厚い。
  • 自由度（サンプル数 $-1$）が大きくなると急速に標準正規分布 $N(0, 1)$ に一致する。
実例で理解する

新レシピA vs 定番レシピBの味評価（2標本t検定）

各グループたった5人（計10人）に10点満点で味を採点してもらい、差があるかを判定。

新レシピ A（5人）
平均 8.0 点
分散 0.50
定番レシピ B（5人）
平均 6.0 点
分散 1.00
// t値の計算（平均差 / 推定標準誤差）
$t = \frac{8.0 - 6.0}{\sqrt{0.75/5 + 0.75/5}} = \frac{2.0}{0.548} \approx \mathbf{3.65}$
自由度 $5+5-2 = 8$ の5%両側限界値は \pm 2.306。
$3.65 > 2.306$ なので「たった5人ずつの評価でも、新レシピが有意に高評価である」と立証できる！

どんな時に使う？

  • 1標本t検定： ある製品の平均重量が規定の「100g」と異なっているかを検査したい時。
  • 2標本t検定（独立・対応あり）： WebサイトのA/Bテストで滞在時間に有意差があるか、投薬の前後で血圧が下がったかを調べたい時。
  • 回帰係数の有意性検定： 単回帰・重回帰分析で、各変数の傾き（係数）が偶然 $0$ でないかを検定する時。
💡 なぜサンプル数30以上で正規分布と言われるのか？

自由度が30を超えると、$t$分布の95%信頼区間の係数は約 $2.04$ となり、正規分布の $1.96$ とわずか数%しか違わなくなるためです。

$F$

3. $F$ 分布（Fisher-Snedecor Distribution）

近代統計学の父フィッシャーが拓いた「分散の比較」

背景と誕生のストーリー

1920年代、ロナルド・フィッシャー（Ronald A. Fisher）がロザムステッド農業試験場で、複数の異なる肥料や土壌による収穫量の差を評価するために創案しました。

3つ以上のグループを比較する際、ペアごとに $t$検定を繰り返すと「偶然どれかが有意になってしまう確率（多重性の問題）」が跳ね上がります。そこでフィッシャーは全体のデータの揺らぎを「グループ間のばらつき」と「偶然の誤差ばらつき」に分解し、「その比率（分散比）」を一発で評価する**分散分析（ANOVA）**を確立しました。

主な性質
  • 正の値同士の比率であるため、必ず0以上の値をとる。
  • 2つの分散が等しい場合、$F$値はおよそ $1$ 前後になる。
  • 分子の自由度 $k_1$ と、分母の自由度 $k_2$ という2つのパラメータを持つ。
実例で理解する

3台のコーヒー抽出機による濃度差（一元配置分散分析）

マシン1、マシン2、マシン3でそれぞれ4杯（計12杯）抽出し、マシンの違いによる差があるかを一括検定。

マシン 1
平均 1.30%
マシン 2
平均 1.45%
マシン 3
平均 1.20%
// F値の計算
$F = \frac{\text{マシン間の分散（要因）}}{\text{各マシン内の抽出ブレ分散（誤差）}}$
もし $F = 6.2$ だった場合（分子自由度 2、分母自由度 9 の5%限界値は 4.26）：
$6.2 > 4.26$ なので、「単なる淹れ方のブレを超えて、マシン間で明確な性能差がある」と判定できる！

どんな時に使う？

  • 分散分析（ANOVA）： 3つ以上の店舗、デザイン案、薬効グループなどの平均値に差があるかを一括検定したい時。
  • 等分散性の検定（F検定）： 2つの工場の製造ラインで、寸法のばらつき（品質の安定度）が同じかどうかを比較したい時。
  • 重回帰分析の適合度検定： モデル全体として目的変数を説明する能力が統計的に有意かを判定したい時。
💡 スネデカーによる「F」の命名

考案者フィッシャーの功績に敬意を表し、親交のあったアメリカの統計学者ジョージ・スネデカーが頭文字をとって「$F$分布」と命名しました。
